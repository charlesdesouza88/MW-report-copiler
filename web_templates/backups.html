Pontos de restauração

{% if not db_mode %}

Pontos de restauração só existem com o banco de dados (DATABASE_URL) ativo.

{% else %}

O sistema guarda uma cópia sozinho antes de qualquer remoção, upload de CSV, importação ou transferência, e a cada 30 minutos de edição. Ficam as 10 cópias mais recentes de cada tipo de dado e uma por dia nos últimos 30 dias. «Restaurar» substitui só aquele tipo de dado; «Desfazer ação inteira» volta tudo o que um upload ou transferência alterou. Em ambos os casos os dados atuais viram um novo ponto, para você poder desfazer.
